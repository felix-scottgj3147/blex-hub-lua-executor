## Frequently Asked Questions

**What operating systems does Blex Hub target?**  
Blex Hub is designed primarily as a Windows desktop experience, with Windows 10 and Windows 11 as the supported target environments.

**Can scripts stop working after a Roblox update?**  
Yes. Roblox updates and executor changes can affect compatibility. Whether a script works depends on the current game version and the executor environment in use.

**Is Blex Hub itself a standalone executor?**  
No. Blex Hub serves as the collection and organization layer for scripts. Loading and running them still requires a compatible Roblox executor.

**Could script use have consequences for my account?**  
Using scripts can carry risks related to platform and individual game rules. Check the applicable terms and proceed at your own discretion.

**Are the scripts managed on the local machine?**  
The project layout indicates local organization of scripts and associated files, allowing content to be managed directly on the user's machine.
